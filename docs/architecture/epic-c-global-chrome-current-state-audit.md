## Current Rendered Chrome

Current preview global chrome remains mostly inherited from Trade:

- Header `main-menu`: `Home`, `Catalog`, `Contact`.
- Header utility controls: search control, account login link when accounts are
  enabled, cart link.
- Mobile drawer: same `main-menu` links plus account utility when rendered.
- Footer `footer` menu: `Search`.
- Footer dynamic policy links: `Privacy policy`.
- Footer platform link: `Powered by Shopify`.

`Catalog` is verified current state but not approved final Epic C IA. It remains
in the route contract so current rendered chrome is testable until C-PBI-010 and
C-PBI-011 replace or reposition it through approved admin work.
