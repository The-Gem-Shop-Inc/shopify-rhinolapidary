## Use Rules

- Preserve source values until a decision owner approves replacement evidence.
- Treat voltage differences as possible market or variant configurations until technical review confirms otherwise.
- Treat assembled dimensions, catalog dimensions, machine net weight, packaged dimensions, crated dimensions, and crated shipping weight as separate attributes when source context supports separate physical states.
- Flag probable typographical errors without correcting them silently.
- Store confirmed machine facts in approved typed fields. `rhino.product_class` and the governed `machine_family` reference foundation remain valid; the legacy `rhino.machine_specs` JSON and string-list `rhino.compatibility` proposals are deprecated by E-PBI-009. E-PBI-010 owns atomic technical/electrical fields, and E-PBI-012 owns compatibility references.
