# Epic L decision and dependency register

**Prepared:** 2026-11-05
**Status:** Proposed; unknown facts remain unknown and no row is approval
**Authority boundary:** This register records evidence needs and next actions. It does not authorize customer claims, Shopify changes, app installs, communications, or production work.

## Blocking scale

- **Critical:** blocks any safe customer-facing or data-collecting implementation in the affected PBIs.
- **High:** permits contract/shell work but blocks activation or publication.
- **Medium:** blocks an optional extension or mature operating state.
- **Low:** refinement that can follow a safe baseline.

## Decision sequencing

The genuinely blocking sequence is:

1. L-DEC-001/002/004 for any warranty publication or claim.
2. L-DEC-005/006/007/008 for repair/support workflow and K-EVID-007.
3. L-DEC-010 before any structured intake, upload, account record, chat transcript, or automation.
4. L-DEC-011/012 before customer-facing manuals, procedures, or diagnostics expand.
5. L-DEC-014 plus L-DEP-001 before choosing or enabling Forms/Flow/custom intake.
6. L-DEC-019 before a safety-notice implementation can be considered release-ready.

L-DEC-015, L-DEC-018, and the custom account/directory implementations are not prerequisites for the initial support foundation and should remain deferred unless the Product Owner changes the milestone.
