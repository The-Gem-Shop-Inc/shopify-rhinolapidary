# Manual QA Evidence Process

## Purpose

Automated tests do not cover every Shopify storefront, admin, checkout, and device condition. Manual QA evidence records what was checked and who accepted it.

## Evidence folder

Use:

```text id="00yeju"
docs/qa/evidence/
```

## File naming

```text id="4bf64l"
YYYY-MM-DD-scope.md
```

Example:

```text id="59pm5p"
2026-07-30-prelaunch-cart-checkout.md
```

## Required evidence

Manual QA evidence should include:

* Date
* Tester
* Browser/device
* Storefront URL
* Theme ID or preview URL
* Scope
* Steps checked
* Result
* Screenshots or notes
* Related PBIs
* Risks/follow-ups

## Launch-required manual QA scopes

At minimum:

* Homepage
* Machine collection
* Primary product page
* Add to cart
* Cart page
* Checkout entry
* Search
* Contact/support
* Mobile viewport
* Desktop viewport
* Store password/launch state
